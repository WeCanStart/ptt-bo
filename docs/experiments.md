# План и журнал вычислительных экспериментов

Все эксперименты запускаются одним скриптом `run_all.py` (стадии через `--only`), каждый прогон — отдельный процесс
с одним потоком BLAS и фиксированным сидом. Сырые результаты каждого BO-прогона (JSON: все значения $f(\mathbf x_i)$,
время итераций, $f^*$) лежат в `results/raw_runs.zip`; распакуйте архив в `results/`, чтобы перерисовать рисунки
без пересчёта (`python run_all.py --plots`).

Общие настройки BO: область $[0,1]^d$ (каждая функция линейно отображена со своей стандартной области),
$n_0 = 20$ начальных точек Sobol, затем по одной точке за итерацию; сиды 0–9 (E7: 0–3).
Метрика (внешний критерий): простой регрет $r_N = \min_{i\le N} f(\mathbf x_i) - f^*$; сводная метрика —
IQM по (задача, сид) от $\log_{10}(r_N / \mathrm{median}\, r_N^{\text{random}})$ с 95% бутстреп-интервалом;
парный тест Уилкоксона по сидам.

## Главные числа

**E9 (базовый эксперимент)**, IQM нормированного log-регрета, меньше — лучше:

| метод | после 40 вызовов | после 100 вызовов |
|---|---|---|
| PTT-EI (наш) | **−0.82** [−0.87, −0.77] | −0.86 [−0.92, −0.81] |
| BoTorch LogEI | −0.59 | −0.80 |
| TuRBO-1 | −0.26 | **−0.98** [−1.05, −0.91] |
| аддитивный GP-EI | −0.25 | −0.61 |
| GP-EI (ARD, приоры) | −0.14 | −0.56 |
| CMA-ES | −0.40 | −0.49 |
| случайный поиск | 0.00 | 0.00 |

Наблюдение (E9 → E13): PTT-EI лучше всех на малых бюджетах, но после ~40 вызовов перестаёт улучшаться.
Преимущество не коррелирует с TT-рангом целевой функции (ранговая корреляция ≈ 0); решающим оказался ANOVA-приор
(E10: с приором zero регрет в 2–4 раза хуже). Локальная модель в доверительной области (TR-PTT, E13) снимает застревание.

**E14 (отложенные задачи)**, после 150–200 вызовов: TR-PTT −1.39 [−1.49, −1.30], LogEI + warp −0.82,
глобальная PTT −0.81, TuRBO-1 −0.80, TuRBO-1 + warp −0.77, CMA-ES −0.44. Гипотезы протокола: TR-PTT лучше TuRBO-1
в конце бюджета (75:15 пар, p = 2·10⁻¹⁰), лучше TuRBO-1 + warp (71:19, p = 2·10⁻⁹), лучше TuRBO-1 после 40 вызовов
(81:9, p = 2·10⁻¹⁴); ранг 2 не хуже ранга 4; warp поверх доверительной области не помогает (46:44, p = 0.5).

## Известные ограничения
Только синтетические функции; d ≤ 20; бюджет ≤ 200; при d = 10 TR-PTT в 1.7–3.6 раза дороже TuRBO по времени
(152–327 с против 90 с на прогон); на Hartmann6 TuRBO остаётся лучшим.
